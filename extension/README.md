# 图库采集助手（Chrome 扩展）

把网页上的图片一键存进本地图库（GemVault）。**纯本地**：扩展只把图片地址/截图 POST 到 `http://127.0.0.1:3001/api/extension/ingest`，由桌面端负责下载与入库。

## 安装（开发者模式）

1. 打开 Chrome → `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」→ 选择本目录（`extension/`）

## 用法

- **单张**：在图片上右键 → 「采集这张图片到图库」
- **整页**：页面空白处右键 → 「采集本页所有图片到图库」（自动过滤宽高 < 400px 的小图，最多 30 张）
- **截图**：点扩展图标 → 「截取可见区域」
- 弹窗里可填**关键词**与**标签**，留空则默认用页面标题

## 注意

- 桌面端需处于运行状态（端口 3001）
- 下载时会自动带上页面来源（Referer），对有防盗链的站点有效
- 接口仅监听 127.0.0.1，不对外暴露
